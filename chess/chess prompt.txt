🧩 Functional Overview

1. Homepage (index.php)

Landing page showing game logo, “Play Now”, “Login”, and “Admin” buttons.

Links to login.php for user access.

Include responsive layout (mobile-first).


2. User Authentication

login.php: Handles user login and signup.

profile.php: Displays username, win/loss stats, and game history.

Sessions must be used for authentication.

Uses MySQL table users (id, username, password, wins, losses).


3. Game Page (game.php)

Displays an 8×8 chessboard using HTML table or grid.

Each square has alternating light/dark theme using CSS.

Chess pieces loaded as images or Unicode icons.

Supports:

Drag-and-drop piece movement.

Move validation (legal moves only).

Check and checkmate detection.

Option to play vs AI or another player.


Move sounds:

move.mp3 for regular moves.

capture.mp3 for capturing pieces.

check.mp3 for check.

game-start.mp3 at match start.

ui-click.mp3 for button interactions.



4. JavaScript Files

game-ui.js:
Handles rendering, animations, highlights, and sound triggers.

Highlight selected pieces and valid move squares.

Animate piece movement.

Update UI for “Check” and “Game Over.”


game-logic.js:
Contains chessboard logic:

Move legality checks (pawn, rook, knight, bishop, queen, king).

Turn control (white/black).

Checkmate/stalemate detection.


game-ai.js:
Simple computer opponent using a basic move-evaluation algorithm:

Selects legal moves at random or based on piece value.

Responds after 1-second delay to simulate thinking.
